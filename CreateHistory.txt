как мне получить apk для установки?

-

Самый простой способ — собрать отладочный APK в Android Studio. Для личного использования его достаточно.

Сборка

В меню выберите Build → Build Bundle(s) / APK(s) → Build APK(s).
Когда внизу справа появится уведомление «APK(s) generated successfully», нажмите в нём locate.
Файл лежит в ShopList/app/build/outputs/apk/debug/app-debug.apk.

То же самое можно сделать из терминала в папке проекта: ./gradlew assembleDebug (на Windows gradlew.bat assembleDebug). Эта команда сработает, если в проекте есть gradle wrapper. Если его нет, используйте меню.

Установка на телефон

Перенесите app-debug.apk на телефон: по USB, через облако или мессенджер.
Откройте файл в файловом менеджере. Android попросит разрешить установку из неизвестных источников для этого приложения (файлового менеджера или браузера). Разрешите и подтвердите установку.

Если телефон подключён по USB с включённой отладкой, можно нажать Run в студии, и приложение установится сразу, без APK-файла.

Подписанный релизный APK
Он нужен, если вы хотите раздавать приложение другим или выложить его в Google Play. Для этого откройте Build → Generate Signed App Bundle / APK, выберите APK и создайте keystore. Файл keystore и пароль к нему храните надёжно: без них вы не сможете выпускать обновления с той же подписью.

Отладочный APK подписан временным ключом студии. При пересборке на другом компьютере ключ будет другим, и новую версию придётся ставить, предварительно удалив старую. Данные приложения при этом сотрутся, поэтому перед удалением сделайте экспорт базы в настройках.

Для векторной иконки точнее всего задать масштаб прямо в XML, а не через мастер Image Asset. Мастер принимает растровые картинки и SVG, а не наш ic_launcher_foreground.xml. Оберните все <path> в <group> с масштабом и центром в середине холста:

xml
<vector xmlns:android="http://schemas.android.com/apk/res/android"
    android:width="108dp" android:height="108dp" android:viewportWidth="108" android:viewportHeight="108">
    <group android:scaleX="0.8" android:scaleY="0.8" android:pivotX="54" android:pivotY="54">
        <!-- сюда все существующие <path> без изменений -->
    </group>
</vector>
Подбор масштаба: 0.8 — хороший старт. При 0.75 всё помещается в безопасную зону даже на круглой маске, при 0.85 иконка крупнее, но ручка тележки может слегка задеваться краем.
Сдвиг: чтобы сместить рисунок, добавьте в <group> android:translateX и android:translateY (например, translateY="2" опустит его на 2 единицы).
